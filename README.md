# Pokedex CLI

A command-line Pokedex built with Python, argparse, and PokeAPI.

## Usage
pokedex search pikachu              look up a Pokemon (metric by default)
pokedex search pikachu --imperial  show height/weight in imperial units
pokedex compare charmander squirtle  compare base stats of two Pokemon
pokedex ability blaze       look up a ability's effect
